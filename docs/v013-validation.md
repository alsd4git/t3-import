Validated on 27 October 2026 with Node.js 24.19.0. The installed artifact also
passes on Node.js 22.23.2.

- Source archive SHA-256:
  `b3b74af1ecd365f163a14f201ba5141f293d950f6213a4f493cf88724ca3a3f8`.

## Schema and writes

The new ceiling is migration 69. Migration 68 creates a partial index for shell
stop requests. Migration 69 creates a contentless FTS5 trigram index and three
message maintenance triggers. Upstream allows this migration to complete without
the extension when SQLite does not support the required FTS5 options.

The importer selects the official 0.1.3 EventSink and ProjectionStore for migration
69. Profiles 62 and 67 retain their earlier runtimes. Unknown and intermediate
migrations remain refused. Production writes never run T3 migrations.

Column validation accepts the absent optional search extension. A present index
requires its generated shadow-table columns and all three maintenance triggers.
Generated schema fixtures omit shadow-table DDL because SQLite creates those
tables with the virtual table, and create tables before dependent triggers.

Backups now use SQLite's backup API rather than VACUUM INTO. VACUUM can renumber
message rowids, breaking their relationship with the contentless search index.
The backup regression test leaves a rowid gap and verifies identical rowids and
working search joins in the recovery copy.

## Verification

- `npm run compat:v2-schema`: schemas generated by all four pinned releases.
- `npm run typecheck`: passed.
- `npm test`: 794 tests in 21 files passed, including import, sync, replacement,
  legacy migration, resumable bindings, rollback and dry-run checks against the
  supported official runtimes.
- `test/v013.test.ts`: search after import/sync/replacement, update/delete
  triggers, extension-free fallback, incomplete-index refusal and backup rowids.
- `npm run package:check`: passed on Node.js 24.19.0 and, with an isolated
  official Node.js binary, 22.23.2. The installed artifact imports a compressed Codex rollout,
  syncs a resumed plain rollout, checks idempotency and verifies all four messages
  are indexed for search.

All fixtures and installations are isolated temporary data. No production
conversations or T3 installations were modified. Windows and Linux checks remain
part of CI and were not executed locally.

Reproduce:

```sh
node scripts/v2/build-runtime.mjs 0.1.3
npm run compat:v2-schema
npm run typecheck
npm test
npm run package:check
```
